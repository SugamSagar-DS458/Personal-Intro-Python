# Personal Introduction Program

## Project Overview
**Goals and Objectives:** 
The objective of this project is to create an interactive command-line Python application that greets users. It demonstrates fundamental programming concepts such as standard input/output operations, variable assignment, and string formatting to create a friendly and personalized user experience.
